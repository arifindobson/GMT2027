# PRD: Mekkah Total Solar Eclipse 2027 Countdown

## Overview
A high-end, responsive web application providing a countdown to the Great Muslim Eclipse (Total Solar Eclipse) on August 2, 2027, specifically for Makkah, Saudi Arabia.

## Event Details
- **Date:** August 2, 2027
- **Location:** Makkah, Saudi Arabia
- **Totality Duration:** ~5 minutes 5 seconds
- **Key Timings (AST - UTC+3):**
  - Partial Begins: 12:01:00
  - Totality Begins: 13:23:00
  - Maximum Eclipse: 13:26:00
  - Totality Ends: 13:29:00
  - Partial Ends: 14:44:00

## Functional Requirements
1.  **Countdown Clock:** Real-time countdown displaying Months, Weeks, Days, Hours, Minutes, and Seconds until the start of totality.
2.  **Phase Indicator:** Display the current status (e.g., "Counting down to Totality", "Totality in Progress", "Eclipse Completed").
3.  **Responsive Design:** Optimized for Mobile, Tablet, and Desktop.
4.  **Aesthetics:** Premium, dark-themed UI with celestial animations (solar corona, moon transitions).
5.  **Local Time Sync:** Automatic conversion/display based on the user's local time while highlighting the Makkah (AST) event time.

## Design Requirements
- **Theme:** Elegant Dark Mode (Charcoal/Black with a subtle texture).
- **Colors (Inspired by @[logo01.png](file:///Users/arifindobson/Documents/IT%20PARAGON/AI-PRD/GMT2027/logo01.png)):**
  - **Primary Gold:** #D4AF37 (Antique Gold) or similar metallic gold gradient.
  - **Background:** #0F0F0F (Deep Charcoal/Black).
  - **Accent:** Soft radiant glows representing the sun's corona.
- **Typography:** Elegant Serif for headers (matching the "2027" in the logo) and a clean Sans-Serif for readability (e.g., Montserrat or Playfair Display).
- **Imagery:** Incorporate Kaaba-centric celestial visuals, mirroring the logo's radiant sunburst.

## Technical Stack
- HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- No external heavy frameworks unless requested (keeping it lightweight and fast).
- CSS Grid/Flexbox for responsiveness.
